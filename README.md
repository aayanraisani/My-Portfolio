# My Portfolio

Personal portfolio website of Aayan Ahmed Brohi, built to showcase my skills, experience and projects for IT Support and Web Development roles.

Live site: https://aayanbrohi.vercel.app

## What's inside

- Home, About, Skills, Projects, Experience and Contact sections
- Light and dark mode
- Responsive layout for mobile, tablet and desktop
- Downloadable CV
- Contact form that opens the visitor's email app

## Built with

- HTML5

- JavaScript
- Bootstrap 5
